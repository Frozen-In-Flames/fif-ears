fif-ears: live demo

Audio perception for agents. fif-ears listens to an audio file as measurement and translates what is in the sound into a structured report (report.json) and a written narrative (report.md) that any model or human can reason over.

How this demo works

  
This page runs the real fif-ears Python package, version 0.1.0, in
     your browser through Pyodide (Python compiled to WebAssembly) with
     numpy and scipy. No analysis code was rewritten in JavaScript. The
     package files are vendored under ears/ next to this
     page, byte-identical to the shipped package (see
     VENDORED.md).

  
One step differs from the command line tool, and it is only the
     decoder: your browser decodes the audio with the Web Audio API,
     where the command line tool uses ffmpeg. The decoded samples are
     handed to the package, and every analysis step after decoding is
     the shipped package itself.


  
The seven layers

  
    
    
  • signal: duration, levels, clipping, spectral summary, stereo width.
    • 
    
  • rhythm: onsets, tempo with auditable metrical levels, beat grid.
    • 
    
  • structure: section boundaries from a novelty analysis.
    • 
    
  • harmony: pitch track, key estimate, per-segment chords with honest nulls.
    • 
    
  • words: speech transcription when a local Whisper engine is installed. In this browser demo it reports not_installed, the same honest result the command line tool gives on a machine without Whisper.
    • 
    
  • events: non-music sound segmentation (silence, speech-like, music-like, noise-like).
    • 
    
  • expression: dynamics contour, groove in milliseconds, timbre proxies, harmonic tension.
    •
